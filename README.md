# ⚙️ Chrono Gears

A puzzle game inspired by the classic Amiga game "Logical" - built with Three.js.

## 🎮 Play Now

**[Play on Vercel](https://logical-game-nine.vercel.app)**

## 🎯 How to Play

1. **Gems** travel along the top track with a countdown timer
2. Gems auto-drop into gears with empty TOP slots
3. **🔄 AUTO-FLOW**: Gems automatically move through tracks to empty slots!
4. **TAP** a gear to rotate it
5. **SWIPE** on a gear to eject a gem in that direction
6. **⚙️ STRATEGY**: Rotate gears to "park" gems away from tracks until you're ready
7. Fill a gear with **4 same-color gems** to clear it!

## ✨ Features

- 🎨 Steampunk aesthetic with bronze gears and glowing gems
- 📱 Mobile-friendly with touch controls
- ⏱️ Countdown timer creates urgency
- 🔄 Auto-flow mechanic for strategic gameplay
- 🏆 Best time tracking per level

## 🛠️ Tech Stack

- **Three.js** - 3D rendering
- **Vite** - Build tool
- **Vanilla JavaScript** - Game logic
